# 帛琉南島永續實踐計畫 (Palau Austronesian Sustainability Action Project)

> 教育部青年發展署「青年百億海外圓夢基金計畫－海外翱翔組」N-10-3  
> 面向對海外探索、永續發展及跨文化交流有興趣的大專院校青年學生之個人探索與實踐入口網

---

## 🌊 計畫簡介

本專案旨在提供大專院校青年學生一個兼具專業深度與實用功能的單檔現代化網頁（Single-File Web App）。依據教育部青年發展署「青年百億海外圓夢基金計畫－海外翱翔組」N-10-3 帛琉南島永續實踐計畫之培訓與考察內容，以南島同族「平等、平視」視角出發，將生硬的 ESG 概念轉化為肉眼可見的田野線索，拒絕獵奇觀光，成為有溫度的文化轉譯者。

---

## ✨ 核心功能亮點

1. **互動式日期探索選單 (Interactive Date Selector)**
   - 完整收錄 **7/14 行前培訓**（銘傳大學基河校區 J616 會議室）與 **7/29 - 8/12 帛琉 15 天實地考察**。
   - 橫向滑軌切換日期，支援按 SDGs 永續目標（SDG 14 海洋、SDG 11 原民社區、SDG 12 責任生產消費、SDG 15 陸域生態、SDG 4 優質教育）主題分類篩選。
   - **天候應變機制**：因應 8/6 颱風外圍環流影響船班停駛，8/06 與 8/10 行程對調（8/06 頁面頂端置頂顯示「因海況不佳，行程已調整」提示；8/06 改為陸域特有種鳥類調查，8/10 對調為洛克群島 BUL 垂釣，Google Maps 景點連結同步更新）。
   - 每日詳細時段安排、田野微訪談任務引導與文化倫理禁忌小叮嚀。

2. **核心景點 Google Maps 一鍵導航**
   - 包含洛克群島南方潟湖、硨磲海域保護區、國合會駐帛琉技術團與 PMDC 水產養殖展示中心、艾萊州百年男人會館（Airai Bai）、貝勞國家博物館、安得貌天使大瀑布、ECO GLASS 琉璃工坊、臺灣駐帛琉大使館等 18+ 處景點。
   - 每張景點卡片附有直連 Google Maps 查詢連結，並分析 E/S/G 田野觀察維度。

3. **行前準備清單（可勾選與自訂，Checklist）**
   - 涵蓋「行政證件」、「海洋永續裝備（珊瑚友善防曬、減塑水瓶）」、「田野研究工具（Photo-Elicitation 影像設備）」與「部落禮儀與生活」。
   - 特別收錄**「雨衣／防水袋」**應對海島熱帶陣雨與颱風外圍環流。
   - 即時計算進度百分比，支援新增個人自訂項目、勾選狀態自動儲存於瀏覽器 `localStorage`。

4. **青年海外圓夢預算花費紀錄 (Budget & Expense Tracker)**
   - 預算儀表板（總預算額度、累計支出、剩餘額度動態計算）。
   - 支援 USD / TWD 即時匯率換算（可自行調整匯率數值）。
   - 內建帛琉真實出海許可證、文化基金、門票等示範開銷。
   - 支援新增支出、刪除記錄、重設與「一鍵匯出 CSV 報表」。

5. **南島共鳴：日常田野英文破冰句型包**
   - 培訓精選微訪談實戰句型（破冰開場、帛琉誓詞回饋、拜訪長老、Bul 禁漁智慧請益、禮貌致歉退場）。

6. **響應式跨裝置體驗 (RWD)**
   - 零外部套件（Zero External Dependencies），純原生 HTML5 + CSS3 + ES6 JavaScript。
   - 電腦、平板、智慧型手機全尺寸適配，支援移動端導航選單與觸控橫向滑動。

## 🚀 快速開始

直接以任何現代瀏覽器開啟專案根目錄下的 `index.html` 即可使用，不需安裝任何 npm 套件或本地伺服器。

```bash
# 複製倉庫
git clone https://github.com/fczxt/palau-sustainability-action.git

# 開啟網頁
open index.html # Mac
# 或直接在檔案總管中雙擊 index.html
```
